Users API

API de gerenciamento de usuários

Node.js • Express • Supabase • PostgreSQL

Uma API REST com operações CRUD, validação de dados e integração com banco de dados.

Aviso sobre o tempo de resposta

Esta API está hospedada em um plano gratuito. Após um período de inatividade, a primeira requisição pode levar cerca de um minuto para responder. As próximas requisições tendem a ser mais rápidas.
